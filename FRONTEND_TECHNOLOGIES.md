# Frontend Технологии Проекта

В этом документе подробно описан весь технологический стек фронтенда проекта **site2**. Проект построен на современных веб-технологиях с фокусом на высокую производительность, анимации и компонентную архитектуру.

## 1. Ядро (Core)

### [Next.js](https://nextjs.org/) (v16.1.1)
-   **Роль:** Основной React-фреймворк приложения.
-   **Использование:**
    -   Используется **App Router** (`src/app`), что обеспечивает поддержку React Server Components (RSC) по умолчанию.
    -   Обеспечивает SSR (Server-Side Rendering) и статическую генерацию для лучшей SEO и производительности.
    -   Управляет маршрутизацией (файловая система внутри `src/app`).
    -   Оптимизация шрифтов и изображений.

### [React](https://react.dev/) (v19.2.3)
-   **Роль:** Библиотека для построения пользовательского интерфейса.
-   **Использование:**
    -   Версия 19 (rc/canary в контексте Next.js 16) предоставляет доступ к новейшим хукам и API.
    -   **Server Components:** По умолчанию в `app/page.tsx`, `layout.tsx` и других файлах без директивы `'use client'`.
    -   **Client Components:** Интерактивные элементы (анимации, управление состоянием) помечены директивой `'use client'` (например, `src/components/Projects.tsx`).
    -   Хуки: `useState`, `useEffect`, `useRef`, `useContext` активно используются для локального состояния и эффектов.

### [TypeScript](https://www.typescriptlang.org/) (v5)
-   **Роль:** Статическая типизация кода.
-   **Использование:**
    -   Весь проект написан на TS (`.ts`, `.tsx`).
    -   Обеспечивает безопасность типов для пропсов компонентов (интерфейсы Props), состояния и API вызовов.
    -   Конфигурация находится в `tsconfig.json`.

## 2. Стилизация и UI

### [Tailwind CSS](https://tailwindcss.com/) (v4)
-   **Роль:** Utility-first CSS фреймворк для стилизации.
-   **Использование:**
    -   Используется новейшая **версия 4** (Alpha/Beta engine), конфигурируемая через CSS (`@import "tailwindcss";` в `globals.css`) и плагины PostCSS.
    -   Стилизация происходит через классы прямо в TSX файлах.
    -   Глобальные переменные (CSS Variables) для темы (цвета, шрифты) определены в `src/app/globals.css`.

### [PostCSS](https://postcss.org/)
-   **Роль:** Инструмент для трансформации CSS.
-   **Использование:**
    -   Используется парсером Tailwind для обработки CSS файлов.
    -   Конфигурация в `postcss.config.mjs` (подключает `@tailwindcss/postcss`).

### [clsx](https://github.com/lukeed/clsx) & [tailwind-merge](https://github.com/dcastil/tailwind-merge)
-   **Роль:** Утилиты для условного объединения классов.
-   **Использование:**
    -   Используются вместе через хелпер `cn` (classname) в `src/lib/utils.ts`.
    -   `clsx` позволяет применять классы по условию (`{ 'hidden': !isOpen }`).
    -   `tailwind-merge` умно разрешает конфликты классов Tailwind (например, `p-2` и `p-4` -> победит последний переданный), что критично для переиспользуемых компонентов.

### [Lucide React](https://lucide.dev/)
-   **Роль:** Набор иконок.
-   **Использование:**
    -   Импортируются как React-компоненты (например, `ArrowUpRight`, `Github`).
    -   Легковесные SVG-иконки, стилизуемые через классы Tailwind (color, size через пропсы или классы).

## 3. Анимация и Эффекты

### [Framer Motion](https://www.framer.com/motion/)
-   **Роль:** Библиотека для декларативной анимации в React.
-   **Использование:**
    -   Компоненты `motion.div`, `motion.section` и т.д.
    -   Анимации появления элементов при скролле (использование хука `useInView`).
    -   Сложные переходы состояний и интерактивные элементы.

### [Lenis](https://github.com/darkroomengineering/lenis)
-   **Роль:** Плавный скролл (Smooth Scroll).
-   **Использование:**
    -   Обертка всего приложения в `src/components/LenisProvider.tsx`.
    -   Нормализует скролл во всех браузерах, делая его инерционным и плавным, что улучшает восприятие параллакс-эффектов и анимаций.
    -   Конфигурируется в `useEffect` для перехвата нативного скролла.

### Custom Fluid Simulation (Собственная реализация в `FluidCursor.tsx`)
-   **Роль:** Интерактивный фон с эффектом жидкости.
-   **Использование:**
    -   Кастомный код, реализующий физику жидкостей (Navier-Stokes equations).
    -   Реагирует на движение мыши.
    -   Компонент полностью написан внутри проекта, не являясь внешней npm-библиотекой (кроме зависимостей React).

## 6. Визуальный стиль и Графика

### Цветовая палитра и Темизация: Глубокий Анализ

Визуальный язык проекта построен на философии **"Digital High-Contrast"** — сочетании строгого технического минимализма с агрессивной, живой цифровой энергией. Это не просто "темная тема с зеленым", это продуманная система визуальной иерархии.

#### 1. Основная Философия: "Тишина и Шум"
Дизайн работает на контрасте двух состояний:
*   **Статика (UI):** Интерфейс намеренно лишен цвета. Он выступает в роли чистого холста. Кнопки, текст, границы — все работает в градациях серого. Это создает "визуальную тишину", позволяя пользователю сосредоточиться на структуре.
*   **Динамика (User Input):** Цвет появляется *только* в ответ на действия пользователя. Жидкостный курсор, ховер-эффекты, активные состояния. Это создает прямую эмоциональную связь: "Я касаюсь — мир реагирует цветом".

#### 2. Акцентный Цвет: Electric Lime ` #B5FF6D `
Этот оттенок выбран не случайно и играет центральную роль в айдентике.
*   **Психология:** Лаймовый неон ассоциируется с цифровой культурой, терминалами ранних компьютеров (CRT мониторы), кодом, новизной и био-люминесценцией. Он выглядит "токсично" и современно.
*   **Функция:** В черно-белом интерфейсе этот цвет работает как "маркер внимания". Блуждая по странице, глаз пользователя моментально цепляется за `#B5FF6D`.
*   **Использование:** Кнопки call-to-action (CTA), активные ссылки, подсветка синтаксиса, элементы загрузки.
*   **Техническое определение:** В CSS переменная `--accent`.

#### 3. Стратегия "Deep Void": Темная тема
Вместо чистого черного (`#000000`) используется глубокий офф-блэк (`#050505`).
*   **OLED Optimization:** На современных экранах `#050505` выглядит как настоящий черный, но при этом смягчает контраст с белым текстом, снижая нагрузку на глаза (eye strain) при длительном чтении.
*   **Smearing Prevention:** Чистый черный на OLED матрицах может вызывать эффект "smearing" (размазывание) при скролле. Офф-блэк помогает этого избежать.
*   **Иерархия Глубины:** На фоне `#050505` сложнее создавать тени, поэтому интерфейс полагается на тончайшие границы (Borders).
    *   *Subtle Border:* `rgba(255, 255, 255, 0.06)` — едва заметные линии, формирующие структуру сетки.
    *   *Active Border:* `rgba(255, 255, 255, 0.1)` — границы интерактивных элементов.

#### 4. Спектр "Fluid Energy" (Градиенты Курсора)
Уникальная особенность проекта — динамическая палитра симуляции жидкости (`FluidCursor.tsx`). Она разрывает монохромность интерфейса взрывом цвета.
Палитра построена на *аналоговой цветовой схеме* (цвета, расположенные рядом на цветовом круге), что обеспечивает плавные градиенты без "грязных" переходов при смешивании.

**Состав спектра (Массив `COLORS`):**
1.  `#b5ff6d` (Primary Lime) — *Точка входа, связь с основным интерфейсом.*
2.  `#6dffb5` (Neon Mint) — *Переход в холодный спектр, ощущение свежести.*
3.  `#6db5ff` (Cyber Blue) — *Классический "технологический" синий, добавляет глубины.*
4.  `#ff6db5` (Hot Pink) — *Резкий контраст, добавляет игривости и энергии.*
5.  `#ffb56d` (Solar Orange) — *Возвращение к теплу, замыкает круг к лаймовому.*

**Физика смешивания:**
В отличие от CSS градиентов, эти цвета смешиваются по физической модели Навье-Стокса.
*   При быстром движении мыши цвета разделяются.
*   При остановке они диффундируют (растворяются) друг в друге, создавая уникальные, никогда не повторяющиеся оттенки.
*   Параметр `DYE_RESOLUTION: 1024` обеспечивает отсутствие пикселизации ("лесенки") на краях цветовых пятен.
*   Высокое значение `DENSITY_DISSIPATION: 3.5` заставляет цвет исчезать быстро, оставляя ощущение мимолетности взаимодействия, как след на воде.

#### 5. Типографическая Палитра
Цвет текста также строго систематизирован для обеспечения читаемости:
*   **Primary Text (`#ededed`):** Основной контент. Не чистый белый, чтобы не "выжигать" глаза на темном фоне.
*   **Muted Text (`#888888`):** Второстепенная информация, мета-теги, даты. Имеет контрастность достаточную для чтения, но визуально "отступает" на задний план.
*   **Subtle Text (`#666666`):** Декоративные подписи, плейсхолдеры.

#### 6. Светлая Тема: Инверсия
Хотя проект явно "native dark", светлая тема (`light mode`) реализована полноценно.
*   **Background:** `#ffffff` — чистый белый для максимальной "стерильности".
*   **Foreground:** `#171717` — мягкий черный для текста.
*   **Accent:** Лаймовый цвет `#B5FF6D` на белом фоне теряет контрастность текста, поэтому в светлой теме он используется больше как *фоновый* элемент для бейджей или декораций, а не для текста.
*   **Borders:** `rgba(0, 0, 0, 0.1)` — полупрозрачный черный создает ощущение чертежа на бумаге.

#### 7. Микро-взаимодействия (States)
Цвет играет ключевую роль в обратной связи (Feedback loop):
*   **Selection (Выделение текста):** Вместо стандартного синего используется `rgba(255, 255, 255, 0.15)`. Это сохраняет эстетику "бесцветности" даже при утилитарных действиях.
*   **Focus Ring:** Клавиатурная навигация подсвечивается акцентным цветом, обеспечивая доступность (Accessibility) без нарушения стиля.
*   **Glassmorphism:** В проекте практически откахались от сильного размытия (blur) в пользу прозрачности, чтобы сохранить четкость линий и "технический" характер дизайна.

А вот определение глобальных CSS переменных: [globals.css](src/app/globals.css#L3-L21).

### Типографика
Используются новейшие вариативные шрифты от Vercel (`next/font/google`):
-   **Sans:** `Geist Sans` — современный гротеск для основного текста.
-   **Mono:** `Geist Mono` — для кода и технических элементов, подчеркивая "инженерный" стиль портфолио.

### Графические компоненты

#### 1. Interactive Blob (`InteractiveBlob.tsx`)
-   **Технология:** Canvas API + Математика 3D проекции (без тяжелых библиотек вроде Three.js).
-   **Реализация:**
    -   Рендерит сферу из точек (Point Cloud), рассчитанных по формулам сферических координат.
    -   Реализует ручную проекцию 3D точек на 2D плоскость холста.
    -   Поддерживает вращение мышью (drag) и постоянную морфинг-анимацию (искажение формы со временем).

#### 2. Fluid Cursor (`FluidCursor.tsx`)
-   **Технология:** High-performance симуляция физики (предположительно WebGL/Canvas).
-   **Особенности:**
    -   Параметры симуляции: `DENSITY_DISSIPATION` (растворение), `VELOCITY_DISSIPATION` (затухание скорости), `CURL` (завихрения).
    -   Создает эффект "чернил в воде", смешивая цвета из палитры при движении мыши.

#### 3. Interactive Background (`InteractiveBackground.tsx`)
-   **Технология:** Framer Motion (`useSpring`, `useMotionValue`).
-   **Эффект:** Создает параллакс-эффект для декоративных частиц, которые плавно следуют за курсором с физикой пружины (Spring Physics), создавая ощущение глубины.

#### 4. SVG паттерны (`globals.css`)
-   Класс `.bg-lines` добавляет фоновый узор из изогнутых линий через CSS `background-image: url("data:image/svg+xml...")`.
-   Это легкий способ добавить текстуру без загрузки внешних изображений.

## 7. Управление состоянием (State Management)

### React Context API
-   **Роль:** Глобальное состояние приложения.
-   **Использование:**
    -   Реализовано в `src/lib/context.tsx`.
    -   **Language Context:** Управляет текущим языком (RU/EN) и переводами интерфейса.
    -   Обеспечивает доступ к словарю переводов `t('key')` в любом компоненте.
    -   Вероятно, также управляет глобальными настройками UI (например, включение/выключение эффекта курсора).

## 4. Структура фронтенда

-   **`src/app/`**: Страницы и глобальные макеты (Layouts).
-   **`src/components/`**: Переиспользуемые UI блоки, большинство из которых являются клиентскими (`'use client'`) из-за наличия анимаций.
-   **`src/lib/`**: Утилиты и контексты, отделенные от UI логики.
